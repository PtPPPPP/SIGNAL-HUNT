# v0.9.0-rc1 桌面发布与现场验收

当前状态：内部验收候选版，不能标记为 v1.0.0。

## 可重复构建

构建机必须使用 Node 24.15.0。先执行 `node --version`，输出必须为 `v24.15.0`；随后执行：

```powershell
npm ci
npm run verify:desktop
```

该命令会检查代码、构建安装包和 ZIP、检查主程序与 `app.asar`、运行已打包 Electron 冒烟，并在 `out/make/SHA256SUMS.txt` 写入四个文件的 SHA-256：安装包、ZIP、主程序和 `app.asar`。

本次开发机已验证的桌面链路：大屏抽奖，`Ctrl + Shift + S` 打开工作人员端，确认兑奖，结束展示后大屏回待机；返回大屏后控制窗口隐藏不销毁，再次按快捷键可打开且状态与记录保持一致。

## 最终展台彩排（必须人工完成）

在最终 Windows 展台电脑全新安装后，断网执行一次完整流程，并检查触控、100%/125%/150% 缩放、16:9 显示、窗口/全屏/Kiosk、强制关闭后的恢复、备份恢复。

随后完成 5 分钟高频抽奖与 8 小时持续运行。上述人工验收未完成前，禁止发布为 v1.0.0。
